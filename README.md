# Selim Uysal — Software Engineering Portfolio

**Live site:** https://selimuysal.github.io/

A bilingual (English/Turkish), responsive portfolio focused on verified software engineering work, applied AI interests, technical experience and independent writing.

## Information architecture

- `index.html` — professional introduction, selected work, research direction, essays, experience, education and contact
- `projects.html` — searchable/filterable project directory
- `case-studies.html` — technical case studies with scope and evidence
- `articles/` — bilingual, source-led essays
- `assets/data.js` — central content model for projects, experience, education and writing
- `assets/site.js` — rendering, language, theme, search and filtering
- `assets/site.css` — responsive design system

## Portfolio principles

- Prioritise shipped software, implementation details and verifiable evidence.
- Distinguish research interests from completed research and peer-reviewed publications.
- Do not expose confidential internship code or data.
- Keep learning exercises and unrelated personal media out of the main engineering showcase.
- No CV files are hosted publicly; they are shared privately when appropriate.

## Development and deployment

The site is a static HTML/CSS/JavaScript project hosted on GitHub Pages. No build step is required. GitHub Pages can deploy from the `main` branch root.

For local preview, serve the repository root with any static HTTP server. Opening the HTML files directly may prevent JavaScript ES module imports from loading.
